# Base de connaissances de l'agent

Fiches de synthèse rédigées pour la démonstration, à partir de textes publics :
Code monétaire et financier (Légifrance), publications de Tracfin, lignes directrices
de l'ACPR et rapports du GAFI. Elles reformulent les textes et ne les remplacent pas :
toute utilisation réelle suppose de vérifier la version en vigueur sur Légifrance.

Une fiche = un fichier Markdown. En-tête obligatoire : `id`, `titre`, `source`.
